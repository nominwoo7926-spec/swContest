# 팀 실험 절차 (Quest 2)

현재 앱의 모든 상자는 부하 추정에 사용하는 **가상 5kg**입니다. 실제 5kg의 저항이나 근육 부하를 측정하지 않습니다. 결과는 VR 작업 자세 추정·처리량·주관적 불편감에 한정해 해석합니다.

## 한 사람의 실험

1. 다른 참가자의 기록이 남아 있다면 앱을 닫고 USB를 연결한 뒤 `Tools/Start-NextQuestParticipant.ps1`을 실행합니다. 이 작업은 먼저 원본 데이터를 PC에 보관하고 새 익명 프로필을 시작합니다. 첫 참가자는 이 단계가 필요 없습니다.
2. Quest 경계 바닥을 맞추고 앱을 엽니다. Y를 짧게 눌러 보고서에서 `HEIGHT`와 `ARM REACH`에 본인의 값을 입력합니다. 화면의 `ESTIMATE`가 `ENTERED`로 바뀌었는지 확인합니다.
3. 벨트 속도와 책상 높이, 완료 개수를 기록합니다. 외부 타이머로 **최소 60초, 권장 90~120초** 작업합니다. 앱에는 구간 종료 알림이 없습니다.
4. 조건을 바꾸기 **전에** Y → `RATE` → 불편감 1~5점을 누릅니다. 1은 낮음, 5는 높음입니다. 점수는 연구자가 원하는 답이 아닌 참가자의 실제 느낌입니다.
5. 보고서에 안전한 제안이 있으면 `APPLY`를 누르고 새 속도·높이를 확인합니다. 같은 시간 다시 작업하고 `RATE`로 평가합니다. 제안이 없거나 안전하지 않으면 억지로 적용하지 않고 그 사실을 기록합니다.
6. 앱을 닫고 USB로 `Tools/Pull-QuestMLData.ps1`을 실행합니다. `Recordings/Quest/FactoryMLCombined/work_blocks_summary.csv`에서 **전·후 두 구간**과 서로 다른 trial 번호, 두 평가점수, 설정값을 확인합니다.

## 팀 기록표에 따로 남길 항목

익명 참가자 번호(P01 등), 실험 날짜, 각 구간의 시작·종료 시각, 전/후 구분, 작업 중단·추적 끊김 여부, 제안 적용 여부, 구간별 실제 불편감 1~5점. 이름·영상 공개 동의는 작업 데이터와 별도로 관리합니다.

한 사람의 전·후 조건은 같은 시간·같은 가상 무게를 사용합니다. 가능하면 순서를 바꾼 반복도 포함해 익숙해지는 효과를 줄입니다. 서로 다른 사람이 같은 `profile_id`로 기록되지 않았는지 확인합니다. 라벨이 없는 CSV나 규칙 추천값을 실제 불편감 정답처럼 사용하지 않습니다.

## 제출 전 확인

Unity 자동 테스트와 Quest 착용 실험은 별개의 증거입니다. 제출 영상에는 실제 Quest 화면의 요청→추천 근거→승인→가상 설비 변경→전후 결과가 보여야 합니다. 제3자 시점은 최신 `.fvr`로 다시 만들어야 하며 이전의 상자-책상 겹침 영상은 사용하지 않습니다. 검증되지 않은 ML 개선률, 실제 하드웨어 조절, 부상 예방 효과는 주장하지 않습니다.
