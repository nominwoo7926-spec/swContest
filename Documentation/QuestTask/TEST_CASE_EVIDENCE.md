# 대표 테스트: 입력 → 기대 → 실제

근거: `PlayVerification.txt`의 Unity Play 모드 합성 추적 입력과 `SceneValidation.txt`. 이는 Quest 착용 시험이 아니다. 실제 기기 칸은 사용자 촬영 후 채운다.

| 사례 | 입력 | 기대 결과 | 자동 테스트의 실제 결과 | Quest 착용 확인 |
| --- | --- | --- | --- | --- |
| 정상 부품 선택 | 컨트롤러 끝을 `1kg`, 이어서 `5kg`에 접촉 | 새 공급 무게 변경, 선택 버튼 눌림 유지 | 5kg 선택 및 눌림 유지 PASS | 미확인 |
| 정상 집기 | 대기 부품 근처에서 양손 Grip | 가장 가까운 손이 한 부품만 집음 | 단일 부품 소유, 중복 소유 방지 PASS | 미확인 |
| 잘못된 집기 | 한 손 Grip만 누르고 부품 접촉 | 집히지 않음 | 집기 차단 PASS | 미확인 |
| 낮은 책상 | 상판을 0.55m로 낮추고 손은 옛 높이에 유지 | 부품도 내려가고 옛 손 높이에서는 못 집음 | 상판·부품 하강과 집기 실패 PASS | 미확인 |
| 적체 포화 | 대기열 12칸 채움 | 무한 생성 없이 새 공급만 대기 | 12칸 상한, 16개 재사용 풀 PASS | 미확인 |
| 추적 손실 | 자동 조절 중 추적값 무효 | 조절 중단, 결과 성공 처리 금지 | `SENSOR WAIT` 및 미확인 결과 폐기 PASS | 미확인 |
| 속도 버튼 | 컨트롤러 끝을 초록 `+`에 접촉 | 벨트 속도 증가 | 실제 속도값 증가 PASS | 미확인 |
| 메뉴 전환 | 왼손 Y 짧게 누르고 다시 짧게 누름 | 작업 버튼 5개 ↔ 개인화 버튼 5개, 동시 노출 없음 | 메뉴 열기·닫기 PASS | 미확인 |
| 조절 승인 | 높이 1.20m 상태에서 에이전트가 낮춤 제안 | 승인 전 목표 유지, 승인 후 가상 목표 변경 | 제안 대기·승인 후 목표 변경 PASS | 미확인 |
| 체형·피드백 | 키·팔 길이 입력 후 10초 이상 작업, 불편감 1~5 입력 | 익명 프로필과 작업 구간 CSV 저장 | 메뉴 렌더와 코드 경로 확인; Quest 조작·실측 저장 미확인 | 미확인 |
| 데이터 부족 | 실측 라벨 CSV 없이 분석 실행 | 가짜 결과/학습 모델을 만들지 않음 | 분석기 중단 확인 | 해당 없음 |

합성 데이터 파이프라인은 네 익명 참가자 간 보류 검증과 네 전후 쌍 요약을 임시 디렉터리에서 통과했다. 이는 **실제 모델 정확도나 개인화 효과 증거가 아니다.** 실물 책상·벨트 제어는 장비가 없어 구현·검증하지 않았다.

실측 효과 비교, 장시간 Quest 프레임 성능, 모델 검증 성능은 이 테스트 표가 증명하지 않는다. 실제 참가자·기기 자료가 확보되면 결과와 실패 화면을 원본 그대로 추가한다.
